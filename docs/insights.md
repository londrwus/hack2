# Insights and direction

## Insights
1. Safety is the main framing. Workers reject "wasted time" / productivity framing.
2. Mental state (fatigue, focus, stress) is a hidden safety risk.
3. Supervisors need to know who is fit for a high-risk task *right now*.

## Candidate concept (hypothesis)
A "fit-for-task" readiness check before high-risk work:
- A 60-second check-in on a phone (reaction-time test plus quick questions on sleep and mood)
- A supervisor dashboard with a green/amber/red status per worker for tasks such as work at height and work near machinery

## Open questions
- Stack, hackathon tracks and judging criteria
- Privacy: will workers trust it, or will it feel like surveillance?
